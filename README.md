# Instagram UI Clone

A responsive Instagram-inspired interface built with HTML and Tailwind CSS.

## Live Demo

[View Live Demo](https://yanakarpovych.github.io/tailwindcss-instagram-clone/)

## Overview

This project is a static front-end implementation of an Instagram-style interface, focusing on layout, responsive design, and UI elements.

## Features

- Responsive layout
- Instagram-style navigation and header
- Stories section
- Post feed with images and captions
- Like, comment, share, and save icons
- Sidebar with profile information and suggestions
- Tailwind CSS utility-based styling

## Technologies

- HTML5
- Tailwind CSS

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/yanakarpovych/tailwindcss-instagram-clone.git
   ```

2. Open `index.html` in your browser.
